# 公众号 HTML 粘贴 & 留言导出

两个面向微信公众号运营的轻量 Chrome 扩展：将 HTML 排版内容粘贴到公众号编辑器，以及将文章留言导出为 CSV。两个工具可独立安装，所有处理均在本地浏览器完成。

![公众号 HTML 粘贴与留言导出](docs/images/readme-banner.png)

## ✍️ 公众号 HTML 排版粘贴

微信公众号编辑器无法直接把 HTML 源代码解析成排版内容。这个扩展可以处理 HTML，并通过富文本粘贴流程写入公众号正文。

- 支持公众号常见的 `section + 内联样式` HTML
- 尝试转换普通网页、卡片和 AI 生成的 HTML
- 支持预览、复制、插入正文，以及读取和修改当前正文

> 💡 适合把 AI 生成的排版、网页文章或已有 HTML 快速放进公众号，也可以在粘贴后继续微调内容和样式。当前输入格式是 HTML，不直接解析原始 Markdown。

### 使用步骤

1. **安装插件：**从 GitHub Releases 下载并解压 `wechat-html-layout-paste-v1.0.0.zip`，打开 Chrome 的 `chrome://extensions/`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后直接包含 `manifest.json` 的文件夹。下载整个仓库时，请选择 `extensions/html-layout-paste`。
2. 打开微信公众号后台的图文编辑页面，点击浏览器工具栏中的“公众号 HTML 排版粘贴”图标。
3. 粘贴 HTML 并检查右侧预览。点击“复制结果”可回到公众号编辑器手动粘贴；点击“插入到正文”则会将内容写入当前光标位置。自动插入更快捷，手动粘贴更容易控制位置。
4. 遇到需要修改的内容时，切换到“编辑正文”，点击“读取正文”或“重新读取”，再在左侧修改 HTML、在右侧查看预览。
5. 修改完成后，点击“应用到正文”替换当前内容；也可以点击“复制结果”后手动粘贴。

## 💬 微信文章留言导出

在微信公众号后台的文章留言管理页中，分页获取当前文章留言，去重后导出为适合 Excel 和 WPS 打开的 CSV 文件。

- 自动识别文章并分页获取留言
- 导出昵称、内容、时间、点赞数、IP 地区、精选、置顶和回复等字段
- 使用 UTF-8 BOM，减少 CSV 中文乱码问题

> 💡 适合在活动或文章发布后整理读者反馈、筛选高赞留言，或者使用 Excel、WPS 继续统计和归档。

### 使用步骤

1. **安装插件：**从 GitHub Releases 下载并解压 `wechat-comment-exporter-v1.0.0.zip`，打开 Chrome 的 `chrome://extensions/`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后直接包含 `manifest.json` 的文件夹。下载整个仓库时，请选择 `extensions/comment-exporter`。
2. 登录微信公众号后台，打开需要导出留言的文章留言管理页。
3. 等待页面中的留言列表完全显示，通常需要 2–5 秒。
4. 点击浏览器工具栏中的“微信文章留言导出”图标，确认识别到正确文章后，点击“导出全部留言”。
5. 导出期间不要关闭弹窗；完成后可在浏览器下载列表中找到 CSV 文件。

### ⚠️ 注意事项

打开留言管理页后，请先等待留言列表完全显示，通常需要 2–5 秒。如果页面已经打开较长时间、切换过文章，或出现 `ret=-1 / system error`，请刷新页面，等待留言重新显示后再导出。导出过程中请勿重复点击、切换文章或关闭扩展弹窗。

## ⚠️ 已知限制

- 微信编辑器会二次过滤 HTML 和 CSS，复杂动画、伪元素、交互脚本和完整网页布局无法保证保留。
- 外链图片可能受来源和微信平台限制，需要重新上传或配图。
- 功能依赖微信公众号后台当前的页面结构与接口行为，微信更新后台后可能需要重新适配。
