# 公众号 HTML 排版粘贴

一个面向微信公众号编辑器的轻量浏览器扩展。它可以把 HTML 中的 CSS 样式转成更适合公众号的内联样式，再以富文本格式写入剪贴板，方便粘贴到公众号正文编辑器。

## 功能

- 粘贴 HTML，并自动处理其中的 `<style>` 规则
- 将常见完整网页 HTML、文章 HTML 和卡片 HTML 转成公众号流式结构
- 清理部分公众号不兼容的样式
- 将固定宽度图片和普通内容调整为响应式显示
- 尽量保留 SVG 互动结构、小程序卡片和跳转链接
- 读取公众号编辑器中的 HTML 源码
- 编辑、整理并预览 HTML
- 将修改结果直接应用回公众号正文
- 将处理后的富文本写入系统剪贴板

## 安装

该扩展目前未发布到浏览器扩展商店，需要通过开发者模式安装。

### Chrome

1. 下载或克隆本项目。
2. 打开 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目文件夹。

### Microsoft Edge

1. 下载或克隆本项目。
2. 打开 `edge://extensions/`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择本项目文件夹。

安装后建议将扩展固定到浏览器工具栏。

## 使用方法

### 粘贴 HTML 排版

1. 打开微信公众号后台的图文编辑页面。
2. 点击浏览器工具栏中的扩展图标，打开“公众号 HTML 排版粘贴”面板。
3. 在“HTML”区域粘贴 HTML 代码，并在右侧查看缩略预览。
4. 点击“插入到正文”，内容会插入打开插件前的光标位置；如果没有可恢复的光标，则追加到正文末尾。
5. 也可以点击“复制结果”，再回到正文按 `Command + V` 或 `Ctrl + V`。

只有在用户主动点击“插入到正文”或“应用到正文”后，扩展才会修改公众号编辑器内容；也可以只复制结果后手动粘贴。

### 查看或修改源码

1. 切换到“编辑正文”。
2. 点击醒目的“读取正文”按钮；需要刷新时点击“重新读取”。
3. 在左侧修改 HTML，并在右侧查看结果。
4. 点击“应用到正文”，修改结果会直接同步到公众号编辑器。
5. 需要保留副本时，也可以点击“复制结果”。

“应用到正文”会先同步选中全文，再通过微信公众号编辑器自己的富文本粘贴流程替换当前正文，不会在原文后追加。如果微信拒绝自动写入，扩展会自动复制结果并提示手动粘贴，不会强制修改编辑器 DOM。

### 预览

输入或修改 HTML 时，右侧会按公众号正文的 677px 画布等比缩略显示处理结果。公众号编辑器仍可能对最终内容进行二次过滤，因此发布前请在公众号后台检查一次。

## 面板的打开与关闭

- 点击浏览器工具栏中的扩展图标：打开面板。
- 点击面板右上角 `×` 或按 `Esc`：关闭面板。
- 页面中不会常驻悬浮按钮。

## 权限说明

扩展只申请完成核心功能所需的权限：

- `clipboardWrite`：在用户点击操作按钮后，将处理过的 HTML 写入剪贴板。
- `activeTab`：仅在用户点击扩展图标后，临时访问当前公众号页面。
- `scripting`：在用户点击后加载转换工具和操作面板。

本项目不包含统计、账号登录、远程上传或自建网络请求逻辑，也不会将文章内容发送到第三方服务器。

## 兼容性与限制

- 主要面向 Chromium 浏览器和微信公众号图文编辑器。
- 微信公众号可能继续过滤部分标签、CSS 属性或互动效果。
- 内置 CSS 转换适合常见选择器，不是完整的 CSS 解析器；复杂的 `@media`、动画和嵌套规则可能无法完整转换。
- 外链图片能否长期显示取决于图片来源和微信公众号的处理方式。
- 请只处理来源可信的 HTML，并在发布前检查排版、链接和移动端效果。

## 项目结构

```text
mp-extension/
├── manifest.json   # Manifest V3 配置
├── background.js   # 浏览器工具栏图标交互
├── transformer.js  # 本地 HTML 安全清洗与兼容转换
├── content.js      # 面板、公众号编辑器适配与剪贴板逻辑
├── icon-source.png # 当前角色图标原图
├── icon16.png      # 浏览器小图标
├── icon32.png
├── icon48.png
└── icon128.png
```

## 更新本地扩展

修改代码后：

1. 打开浏览器扩展管理页。
2. 找到“公众号 HTML 排版粘贴”。
3. 点击“重新加载”。
4. 刷新已经打开的微信公众号页面。
